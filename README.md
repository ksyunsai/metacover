# 메타커버 침수이력 및 범람예상도

[심사용 지도 열기](https://ksyunsai.github.io/metacover/)

수원시 4개 구, 용인시 3개 구와 오산시의 지방하천 50년 빈도 범람예상도를 한 화면에 표시합니다. 지도 이동과 확대 수준에 맞춰 한국에스리 Living Atlas에 현재 범위의 범람 지도를 요청합니다. 침수 깊이는 한강홍수통제소의 5개 등급을 따릅니다. 분홍색 윤곽은 전체 화면에서 좁은 하천 주변의 예상 범람 구역을 찾기 위한 강조 표시입니다.

조회 지역을 선택하거나 지도를 확대해 도로와 범람 구역을 함께 살펴보세요. 위성영상에서도 같은 위치의 범람 구역이 표시됩니다. 지도에서 한 지점을 누르고 **이 위치 공식 지도**를 선택하면 경기기후지도에서 같은 위치를 확인할 수 있습니다.
