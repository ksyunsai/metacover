# 메타커버 침수이력 및 범람예상도

수원시·용인시·오산시의 침수 기록과 지방하천 범람예상도를 살펴보는 모두의 창업 심사용 지도입니다.

**[심사용 웹지도 열기](https://ksyunsai.github.io/metacover/)** · [GitHub에서 세 도시의 침수 기록 보기](./review.geojson)

공개 지도에서 도시를 선택한 뒤 기록의 출처와 위치 기준을 확인할 수 있습니다. 위치 표시는 기록이 가리키는 장소 주변을 찾기 위한 기준점입니다.

지방하천 50년 빈도 범람 범위와 침수심은 [한강홍수통제소 공식 지도](https://www.floodmap.go.kr/region/)에서 확인할 수 있습니다. 원자료를 보유한 경우에는 [메타커버 범람예상도 화면](./forecast/)에서 메타커버 지도 ZIP을 선택해 브라우저에서 열 수 있습니다.
