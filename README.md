# 메타커버 침수이력 및 범람예상도

[심사용 지도 열기](https://ksyunsai.github.io/metacover/)

첫 화면에서 수원·용인·오산의 8개 지역을 고르고, 분홍색으로 표시한 범람 위치를 확대할 수 있습니다. 마우스나 손가락으로 지도를 끌어 이동합니다.

지도에서 한 곳을 누르고 **이 위치 공식 지도**를 선택하면 경기기후지도의 지방하천 50년 빈도 화면이 그 부근에서 열립니다. 첫 화면의 범람예상도는 고정 해상도의 시연 이미지입니다. 레이어를 끄면 도로지도를, **위성영상**을 선택하면 같은 위치의 위성 배경을 볼 수 있습니다.
